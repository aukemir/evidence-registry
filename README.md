# Aukemir Evidence Registry

**Public, evidence-bounded record for the Human De Novo Capability program.**

Aukemir's North Star is to engineer genuinely new human capabilities beyond the native human repertoire. This registry exists to keep that ambition separate from what has actually been demonstrated.

Current execution is **H1 / CP-01: Computational Capability Substrate**. The first controlled substrate is Finite-Horizon Local Intervention Geometry (LIG). LIG is a current technical testbed for specification, measurement and falsification; it is not the company endpoint, a neural code or a biological mechanism.

The cross-substrate capability-engineering method is currently **CEM-E0 — architecture only**. No general capability-engineering method has yet been demonstrated.

The purpose of this repository is simple:

> **Make it easy to distinguish what has been built, what has been tested, what has failed, and what remains unknown.**

## Evidence ceiling

**Current public evidence ceiling: internal technical / synthetic evidence and internally completed held-out technical evaluation.**

External computational executions returned: **0**. Human participants and human data: **0 / 0**.

No item in this registry should be interpreted as evidence of human learning, far transfer, a de novo human capability, H3 synthetic capability, H4 neural capability, H5 biological capability, biological efficacy, workflow value or product-market fit unless that evidence is explicitly added through a future governed update.
